# Radiant Guardian

**Frontier Signal Integrity**

> Explore boldly. Verify rigorously.

Radiant Guardian (RG) is a companion profile within Bridge Node 7's Frontier Intelligence Workflows for investigations where novelty, ambiguity, source genealogy, predictive content, strategic surprise, or self-sealing narratives require controls beyond ordinary claim organization.

## Mission

**Protect the boundary between possibility and knowledge.**

RG does not determine truth. It preserves unusual possibilities while preventing testimony, interpretation, repetition, or generated hypotheses from silently acquiring evidentiary status.

## Operating loop

```text
Receive → Preserve → Genealogy → Hypothesize → Red-team → Predict → Test → Update → Learn
```

## Creative Psionics boundary

Creative Psionics is an explicit hypothesis-generation mode:

- maximize hypothesis diversity;
- search for hidden assumptions and second-order effects;
- propose unconventional explanations and experiments;
- assign generated hypotheses **no evidentiary weight merely for being generated**.

Reality, evidence, and accountable human review govern what survives.

## Evaluation order

1. Run/inspect the relevant PI assessment and validation.
2. Validate the RG companion case.
3. Resolve and hash-check the referenced PI validation.
4. Run RG deterministic controls.
5. Produce the RG validation record.
6. Preserve findings and route consequential conclusions to human review.

RG must never mask or downgrade an upstream PI finding.
