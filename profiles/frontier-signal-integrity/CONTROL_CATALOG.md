# Radiant Guardian Control Catalog v0.1

| ID | Finding | Trigger | Purpose |
|---|---|---|---|
| RG-01 | `RG-UPSTREAM-PI-UNRESOLVED` / `RG-UPSTREAM-PI-REVIEW-REQUIRED` | PI validation missing, hash mismatch, ID mismatch, or already requires review | RG cannot outrun upstream evidence integrity |
| RG-02 | `RG-SIGNAL-CLAIM-COLLAPSE` | Reported/inferred signal is declared as established fact | Preserve signal/claim boundary |
| RG-03 | `RG-INDEPENDENCE-OVERSTATED` | Independent-root count is overstated or required corroboration lacks multiple roots | Prevent repetition from becoming corroboration |
| RG-04 | `RG-ANCHOR-EXTENSION-BRIDGE-MISSING` | Real-anchor → extraordinary-extension flag lacks bridge evidence | Prevent factual laundering across a causal gap |
| RG-05 | `RG-SELF-SEALING-WITHOUT-DISCRIMINATOR` | Self-sealing risk has no linked discriminating test | Preserve falsifiability and learning |
| RG-06 | `RG-PREDICTION-NOT-FROZEN` | Open prediction lacks frozen timestamp/window/criteria | Prevent retrospective prediction rewriting |
| RG-07 | `RG-PREDICTION-RESOLUTION-INCOMPLETE` | Success/failure/ambiguous/unresolved criteria are incomplete | Make resolution auditable |
| RG-08 | `RG-DISCRIMINATING-TEST-INCOMPLETE` | Test cannot separate at least two hypotheses with observable evidence and a decision rule | Convert debate into learning |
| RG-09 | `RG-GENERATED-HYPOTHESIS-PROMOTED` | AI-assisted/Creative-Psionics hypothesis receives automatic evidentiary weight | Keep creativity epistemically bounded |
| RG-10 | `RG-UPDATE-RECEIPT-INCOMPLETE` | Material state change lacks evidence delta, rationale, reviewer, time, or reversal trigger | Preserve belief history |
| RG-11 | `RG-PUBLIC-BOUNDARY-VIOLATION` | RG permits release when upstream PI says do not release | Fail closed on public boundary |
| RG-12 | `RG-PROOF-LOOP-INCOMPLETE` | Active decision/action/outcome tracking lacks reassessment trigger or learning record | Make real-world outcomes improve the system |

A control finding establishes only that the configured condition fired. It does not establish the external claim's truth or falsity.
