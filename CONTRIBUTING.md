# Contributing

Thank you for your interest in Frontier Intelligence Workflows.

- Open a GitHub Issue for defects, clarifications, or proposed improvements.
- Keep changes additive, reviewable, and consistent with the repository's public boundary and validation gates.
- For collaboration beyond routine contributions, see [Innovation Partnerships](https://bridgenode7.com/partner/).

Community health defaults for Bridge Node 7 also apply via the organization `.github` repository.
