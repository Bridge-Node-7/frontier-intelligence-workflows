# Perception Integrity Assessment Template

The adjacent JSON file is a fictional, schema-valid starting point for adopter testing.

1. Copy it into an approved repository path, such as `profiles/perception-integrity/examples/FIW-SYN-ADOPTER/PIA-FIW-SYN-ADOPTER.json`.
2. Replace only the fictional fields with synthetic, sanitized, or clearly public information.
3. Run `scripts/run_perception_integrity.py` with an explicit UTC evaluation time.
4. Treat the output as a review input. It never authorizes action or public release.
5. Record a separate human-review decision when the assessment supports a real decision.

Do not place client work, supplier intelligence, patent strategy, credentials, controlled information, or operational vulnerabilities in this public repository.
