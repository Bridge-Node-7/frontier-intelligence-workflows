# Security Test Baseline

The public regression suite exercises the safeguards FIW publicly claims for repository and release integrity.

Coverage includes approved file structure, portable paths, selected credential and local-path patterns, workflow integrity, source-text safety, link and version consistency, synthetic traceability, manifests, deterministic release construction, output-location enforcement, source-tree immutability, and offline example behavior.

These checks reduce defined repository and release risks. They are not a complete security, data-loss-prevention, malware-detection, or truth-verification system.
